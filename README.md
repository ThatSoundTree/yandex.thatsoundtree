# Yandex OAuth Token Getter

Простое React приложение для получения Yandex OAuth токена.

## Установка

```bash
npm install
```

## Запуск

### Разработка

Запустите Vite dev server:
```bash
npm run dev
```

Приложение будет доступно на `http://localhost:5173`

Для работы API endpoints также запустите сервер:
```bash
npm start
```

### Production

Соберите приложение:
```bash
npm run build
```

Запустите сервер:
```bash
npm start
```

Приложение будет доступно на `http://localhost:3000`

## Переменные окружения

- `PORT` - порт сервера (по умолчанию 3000)
- `BACKEND_URL` - URL бэкенда для перенаправления после получения токена
- `OAUTH_URL` - URL для авторизации Yandex OAuth (по умолчанию используется стандартный URL)

## Использование

1. Откройте приложение в браузере
2. Нажмите "Авторизоваться через Yandex"
3. После авторизации скопируйте URL из окна авторизации
4. Вставьте URL в поле ввода и нажмите "Отправить"
5. Токен будет отправлен на указанный бэкенд
